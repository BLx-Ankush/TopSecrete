Deep Dive: Phase 4 Upgrades

👁️
Vision & App Automation

ALICE replaces standard OS APIs with a Vision-Language Model (Gemini 2.0 Flash). Phase 4 adds Mental Map Caching and Active Window Cropping, slashing latency.

✅ Where ALICE Excels
  • Mental Map Caching: After the first API call, ALICE caches the UI structure via pixel hash. Subsequent actions on the same static screen take ~50ms instead of 3000ms.
  • Intelligent Cropping: Only the active window bounding box is sent to Gemini, reducing base64 token payload by 50-80%.
  • Animation Quiescence: ALICE natively waits for screen elements to stop moving (via RMS pixel diff) before snapping a screenshot, preventing missed clicks.
❌ Where ALICE Lacks
  • API Rate Limits: Even with caching, heavily navigating through highly dynamic unique UI pages can bump into Gemini's RPM/TPM token limits.
  • High VRAM for Local Fallback: Local visual processing (if cloud is unavailable) requires large VRAM GPUs not found on standard laptops.
🎙️
Voice & Audio Fluidity

Using LiveKit WebSockets and direct speech-to-speech multimodal models, ALICE achieves ~280ms latency. Phase 4 hardens this with noise adaptation and offline fallbacks.

✅ Where ALICE Excels
  • Offline Fallback Router: A PingWatchdog constantly monitors API latency. If ping drops >300ms, ALICE seamlessly reroutes audio to local Whisper-Tiny and an Ollama LLM.
  • Adaptive VAD: Before the session starts, ALICE samples ambient mic noise and dynamically adjusts her silence threshold—preventing false cut-offs in loud environments.
  • Neural Interruption: You can barge in and talk over her naturally without hitting a button.
❌ Where ALICE Lacks
  • Degraded Reasoning Offline: The local fallback model (e.g., Llama 3 8B) cannot match Gemini Flash's complex reasoning or coding capability when the internet is down.
🧠
Memory & Contextual Awareness

ALICE uses Mem0 as a vector database. Phase 4 fixes "hallucination gaps" by auto-summarizing sessions and resolving conflicting memories across time.

✅ Where ALICE Excels
  • Session Auto-Summaries: On disconnect, ALICE sends the last 60 turns to Gemini to extract a JSON list of key facts, preferences, and open threads, saving them permanently.
  • Conflict Resolution: When recalling memories, ALICE detects negations/contradictions (e.g. "I love cats" vs "I hate cats"). She auto-weighs by recency and surfaces the conflict verbally to the user.
❌ Where ALICE Lacks
  • No Passive Visual Memory: Windows Copilot "Recall" takes passive screenshots 24/7. ALICE only remembers what is explicitly spoken or queried during active conversational sessions.
⚙️
System & Security Integration

ALICE bridges the gap between software APIs and the physical world. Phase 4 v2.0 introduces Conversational Security, eliminating manual configuration entirely.

✅ Where ALICE Excels
  • Conversational Manifest: When ALICE hits a restricted folder, she verbally asks for permission ("Should I access your D: drive?"). If approved, she writes the path into her own security manifest.
  • Onboarding Wizard: On first launch, ALICE walks the user through a voice onboarding flow to securely map project folders, external drives, and apps.
  • Cross-Platform Strategy: `os_adapter.py` abstracts system commands behind a unified interface, allowing ALICE to run natively on Windows, macOS, or Linux.
❌ Where ALICE Lacks
  • Onboarding Dependence: If a user skips the onboarding wizard or gives vague directory names via voice ("my work stuff"), ALICE may struggle to map the exact system path without user intervention.
